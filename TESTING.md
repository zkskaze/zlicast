# Провере
Проверити чујност декодирањем емитованих бајтова, прикључење два слушаоца на исти програм, промену нумере без нове HTTP везе, опоравак, пријаву, отпремање и поновно покретање.


Прва провера на Windows-у: go test -v engine.go engine_test.go је прошла за MP3 и AAC. По два HTTP клијента спојена преко net.Pipe деле најмање 8.000 идентичних бајтова. Декодирани врх је 9.992/32.767 за MP3 и 8.087/32.767 за AAC. Окружење блокира TCP loopback за shell клијенте, па тест користи стварне HTTP поруке преко меморијских конекција.

TestLocalRadioWorkflow пролази. Проверава пријаву, изолацију панела, отпремање истог MP3-а два пута, наслов и трајање из FFprobe-а, промену програма на отвореној вези, креирање/уклањање станице, дневни термин и враћање ZIP копије после поновног покретања.
