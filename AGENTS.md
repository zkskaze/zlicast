# ZliCast
Пиши кориснички текст српском ћирилицом. Први критеријум прихватања је чујан, непрекидан радио. Провери декодирани звук и два слушаоца пре дотеривања интерфејса.

## Архитектура и рад
Један локални Go сервер, један временски ток и FFmpeg енкодер по станици. Слушаоци се прикључују на текући оквир. Администрација живи иза сесије, јавни плејери и стримови имају стабилне адресе. Библиотека користи садржајно адресиране фајлове. Статички WebUI је уграђен у бинарни фајл. Корисничко стање и акредитиви остају изван Git-а.
После функционалне целине ажурирај SPEC.md, PROGRESS.md, README.md и TESTING.md у делу у ком су се променили. Направи засебан Git commit. Провери актуелни код и резултате тестова пре наставка.


Аудио сат је 48 kHz, стерео s16le у блоковима од 20 ms. Један FFmpeg процес кодира станицу, а HTTP слушаоци добијају исте комплетне MP3/ADTS оквире. Спор клијент има ограничен ред.

SQLite користи winsqlite3 на Windows-у и системску libsqlite3 на Linux-у. Медија се нормализује при увозу и чува једном по SHA-256 у WAV 48 kHz stereo s16. За сат садржаја потребно је око 691 MB. SQLite промена стања и audit су атомични.

Преглед ротације и аутоматски избор деле исти редослед. Положај нумере за плејер долази из PCM позиције, а прегледач га допуњава монотоним временом између очитавања статуса.

Студио шаље PCM у 20 ms блоковима преко аутентификованог WebSocket-а. Исти енкодер испоручује HLS преко FFmpeg tee. При измени кодека отвара се нова HTTP веза због промене MIME типа. Нормалне смене нумере, улазак уживо и опоравак задржавају слушаоца. За локалне измене користи race тестове са привременим подацима.

Историја развоја је на локалној грани `main`. Грана `master` чува првобитни снимак. За засебан радни директоријум са историјом из архиве користи `git clone dist/zlicast-history.bundle zlicast-src`.
