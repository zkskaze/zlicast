# Стање пројекта

Пријава у прегледачу преживљава рестарт сервера. Сесије се чувају у SQLite-у изван конфигурационог ZIP извоза.

Једноставан режим има избор и тренутно пуштање песме из ротације. Веб-плејер пушта аудио преко Web Audio-а, а M3U преузимање даје плејлисту за спољне плејере.

Почетни екран **Једноставно** повезује отпремање, ротацију, џингл и вести на једном месту. HTTP стрим чува кратак бафер комплетних оквира за нове слушаоце, а MP3 оквири су независни од оквира послатих пре прикључења.

| Целина | Имплементација |
|---|---|
| Core | Самосталан Windows сервер, две почетне станице, паралелни енкодери, MP3/AAC, јавни плејери, M3U/ICY, опциони HLS. Чујна резервна тема и опоравак енкодера. |
| Automation | Медијатека са превлачењем више фајлова, метаподаци и омот, нормализација, SHA-256 дељење, ротација, џинглови, рекламе, тагови по добу дана и датуму, плејлисте, календар, приоритети, прекид и crossfade. |
| Studio | Микрофон, миксета, звучна табла, музичка подлога, снимак у архиву, снимање и синтеза вести, увод/одјава, истек и реприза. Браузерски студио преноси PCM преко WebSocket-а. Спољни извор користи Icecast HTTP PUT. |
| Administration | Локални .env, сесије, улоге, API токени, audit, webhooks, ZIP backup/restore. Број директних слушалаца, подаци сесије, минутни узорци, графикон, здравље, CPU/RAM сервера и диск. |
| Испорука | Локални EXE, уграђени SvelteKit, Lucide и фонтови. Припремљени Dockerfile, Compose и GitHub Actions за AMD64/ARM64. |

## Шта преостаје за продукцију

- Проба из физичког микрофона у прегледачу, из правог BUTT клијента и на мобилном плејеру ReKaze.
- Вишесатно оптерећење, провера ограничења малог VPS-а, Docker на обе архитектуре и објава у GHCR.
- Допунско бројање HLS публике. Тренутна статистика броји директне HTTP аудио-везе, а минутни графикон задржава до 24 сата података. Врхунац сесије и просечно слушање почињу од покретања енкодера станице. CPU и RAM приказују Go процес.
- За удаљени студио са мањим протоком преостаје WebRTC/Opus транспорт. Садашњи браузерски PCM захтева око 1,54 Mb/s за један активан стерео извор.
- Дугорочно аутоматско снимање спољног извора и подесива компресија мастер библиотеке.

Поновљиве провере су у TESTING.md. За наставак развоја прво направи пробу звука, па мењај функционалну целину.
