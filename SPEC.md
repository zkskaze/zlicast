# ZliCast

Пријава у прегледачу важи 30 дана. SQLite чува хеш идентификатора сесије у засебној табели. Ручна одјава и промена лозинке онемогућавају употребу старог колачића.

Веб-плејер прима 48 kHz, стерео s16le PCM из истог микса који се шаље енкодеру и пушта га преко Web Audio-а. Јачина се подешава од 0 до 100% у прегледачу. M3U има директну адресу и одвојено преузимање датотеке са апсолутном адресом компресованог MP3 или AAC стрима. Песма из ротације може ручно да прекине тренутну песму.

Почетни екран **Једноставно** пружа отпремање музике по станици, избор MP3 џингла који се емитује после задатог броја песама и тренутно пуштање новог или сачуваног снимка. После снимка се наставља ротација. Број 0 искључује правило између песама.
Self-hosted радио за ZKS и CRNBG.ORG. Локални Windows EXE треба да емитује од првог покретања. Docker је други начин испоруке. Основни ток је покрени → пријави се → превуци музику → слушај. Напредне опције су одвојене.

|---|---|
| Станице | Независне станице, логотип, библиотека, битрејт, стрим, статистика, креирање и уклањање током рада. Почетне су ZliFM и Radio Kaze. |
| Библиотека | MP3, FLAC, WAV, OGG, M4A и AAC, групно отпремање, метаподаци, омоти, претрага, тагови, категорије, плејлисте, дељење, дедупликација, нормализација и crossfade. |
| Распоред | Визуелни календар, једнократно, дневно, недељно и месечно понављање, превлачење, копирање дана, приоритет, завршетак нумере или прекид. |
| Аутоматизација | Џинглови по броју песама и времену, идентификација на пун сат, вести, рекламе, размак по извођачу/песми, избор категорије, временски условљени џинглови. |
| Студио | Микрофон, музичка подлога, звучна табла, независне контроле микса, снимање, спољни BUTT извор и аутоматски повратак. |
| Вести и емисије | Снимање у прегледачу, отпремање, архива, репризе, заказивање, прекид за хитне вести, увод/одјава, истек, опциони TTS. |
| Јавни стрим | Један етар по станици, MP3/AAC, битрејт, ICY, M3U, опциони HLS. /stream/{slug}, /listen/{slug}, /api/stations/{slug}/now-playing, history и stats. |
| Статистика | Тренутна и највећа слушаност, просечно трајање, дневни графикон и најслушанији термини, доступност, саобраћај, CPU, RAM, диск и грешке. |
| Администрација | Fallback, откривање тишине и опоравак, hot reload, health API, backup/restore, улоге admin/DJ/editor/viewer, audit, webhooks за Gotify/Discord, API токени. |
| Испорука | Go, SvelteKit, FFmpeg, SQLite, локални .env, WebSocket/WebRTC за студио, један Docker контејнер, GHCR AMD64/ARM64, GitHub Actions. |

Редослед испоруке је Core → Automation → Studio → Production. Проверено стање је у PROGRESS.md и TESTING.md.


Локално издање спроводи критеријум првог старта помоћу две подразумеване станице, оригиналне резервне теме и аутоматског .env фајла. Изабран је PCM преко WebSocket-а за студио. HLS је опција у подешавањима сваке станице.
